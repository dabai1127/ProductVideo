# 产品宣传制作

一款离线使用的网页视频制作工具。导入视频和图片，搭配文字、转场与配乐，制作产品宣传片、功能演示和视频合集。双击 `打开应用.cmd` 或 `index.html` 即可使用，推荐最新版 Edge 或 Chrome。

![](https://github.com/dabai1127/ProductVideo/blob/main/preview.png?raw=true)

## 主要功能

- 自定义素材与文字：导入视频、图片和音乐，编辑标题、说明、标签与联系信息。
- 镜头剪辑：截取片段、调整时长与速度、旋转画面、拖动排序，支持批量导入。
- 12 种画面布局：包含左右分屏、上下图文、全屏叠字、底部字幕、信息卡、电影宽幕和品牌收尾，支持横屏、竖屏与方形。
- 转场与配乐：支持直接切换、交叉淡化、淡入淡出；内置默认音乐，可调音量、替换或移除。
- 工程与视频导出：保存含素材的工程文件，随时恢复编辑；导出 MP4 或 WebM 成片。

## 使用方法

1. **新建项目**：填写工程名和产品名，选择「产品介绍」「空白项目」或「两段视频合成」。
2. **添加素材**：选中左侧镜头，在右侧「素材」中导入视频或图片；也可用「批量添加」一次导入多个文件。设置素材起点、镜头时长和原声音量，拖动镜头调整顺序。
3. **编辑文字**：在「文字」中填写标题与说明。预览中的标题和说明可直接拖动。
4. **选择布局**：在「布局」中选择排版，调整素材缩放与取景。「恢复布局文字位置」可重置拖动调整。「仅展示素材」隐藏文字与装饰；切换布局会退出该模式并恢复文字默认位置。
5. **设置全片**：在「全片设置」中修改画面比例、品牌、颜色及配乐。点击播放预览，点击时间线定位；空格播放或暂停。
6. **保存与导出**：「保存工程」或 Ctrl+S 下载工程备份，「打开工程」恢复编辑。「导出视频」生成成片，可选择是否包含背景音乐。

## 保存与导出说明

- 工程会在当前浏览器自动保存。清理浏览器数据、移动网页或更换浏览器前，请下载工程备份；备份包含视频、图片和音乐。
- 导出时保持页面在前台，耗时约等于成片时长。支持的浏览器可直接导出 MP4，其它浏览器使用 WebM。
- 需要转换为通用 MP4 时，将导出的视频拖到 `转换为MP4.cmd` 上，转换文件保存在原视频旁。这项转换需要 Python 和 FFmpeg。
